# Windows 11 feature audit

Reviewed October 15, 2026 against the installed Vorssaint 3.4.1 (101) and upstream commit `794608a58d8a88608d3c3cb2e4f22373cf52bfdc`. This covers all 77 entries in upstream `AppFeature`, plus README sub-capabilities. The machine-readable version is [feature-audit.json](feature-audit.json).

The baseline is current public Windows 11 and its updated in-box apps. PowerToys and optional third-party utilities are **not** counted as built-in Windows features. Device-dependent and Store-app-dependent availability is stated explicitly. Basic native capabilities are excluded even when Vela could offer a more convenient wrapper. Partial overlap is split: native functionality is excluded, and only the extra capability is eligible for the port.

"Implemented" means source exists. ARM64 and x64 XAML builds pass, and the ARM64 app launches in Windows 11. Onboarding, the panel and key settings flows have been exercised; individual hardware/input claims remain subject to the [verification checklist](verification.md).

## Native functionality excluded

- Per-app volume/routing, output selection, basic microphone levels: Windows Sound and Volume Mixer.
- Alt+Tab/Task View, taskbar previews/cycling/minimize, maximize, Snap layouts/groups, virtual desktops and display moves.
- Mouse acceleration controls, ordinary wheel line counts, vertical scroll direction, precision touchpad gesture mapping, Back/Forward navigation, hover focus and Filter Keys.
- Win+V basic clipboard history and pins, File Explorer cut/paste and F2 rename.
- Ordinary screenshots, annotation, local OCR, QR scanning and basic screen recording through Snipping Tool; ordinary video edits through Clipchamp. Color picking is also excluded: its built-in HEX mode opened successfully in this non-Copilot+ VM, despite conflicting hardware wording in Microsoft's support article.
- Basic notes, Markdown and tabs through current Notepad; basic camera preview through Camera.
- Ordinary app uninstall, temporary-file cleanup, package management and package updates through Windows Settings, Storage Sense, Microsoft Store and winget.
- Process termination, listening-port inspection, core performance graphs, network addresses and battery reports through Task Manager, Resource Monitor, netstat/ipconfig and powercfg.
- Basic wallpaper, desktop and quick system actions, and ordinary power-plan settings.

No replacement for these appears in Vela's runtime feature catalog. The table below records gaps instead of pretending that overlapping tools have complete parity.

## Supplemental capabilities

- **clipboardGuard** — Implemented delay, session-lock and suspend clearing of the current clipboard; Windows history is not deleted.
- **resourceAlerts** — Implemented sustained CPU/memory and low disk alerts. Separate NVIDIA thermal alerts are implemented subject to driver capability.
- **pasteImage** — Implemented PNG save picker; no Explorer extension.
- **displayDimmer** — Per-monitor click-through dimming overlays implemented; monitorBrightness separately provides DDC/CI hardware brightness when the connection reports support.
- **messagingDownloads** — Implemented explicit folder selection, bounded metadata scan, age review, selected-file recycling and changed-file/reparse-point checks. No automatic deletion or message database access.
- **settingsBackup** — Implemented schema-checked JSON import/export, ordering and preserved disabled-feature settings.
- **onboarding** — Implemented four native WinUI steps; selections persist between launches.
- **languages** — English only in this initial port; other language resources deferred.
- **thermalAlerts** — Implemented NVIDIA temperature threshold, sustained duration, cooldown and no-hardware behavior. Real RTX 3080 readings remain unverified.
- **savedLayouts** — Implemented as savedLayouts: named custom positions, display-relative restore and one-step undo; no Snap engine or custom snapping gestures.
- **windowSearch** — Implemented as windowSearch: title/app search, display filter and activation; no Alt+Tab replacement.
- **imagePins** — Implemented clipboard/file image pins, six-preview limit, native Mica windows, topmost toggle and close-all. Nine backend integration checks pass per architecture. Installed ARM64 file/clipboard rendering, topmost/unpin, resizing, Esc, close-all and feature-disable cleanup passed; the six-pin UI limit and exit cleanup remain unchecked.

## Remaining work

The initial app intentionally has no placeholder feature switches. The unimplemented residuals above remain port work, including additional hardware sensor/fan backends, preferred-audio automation and safe amplification, Bluetooth sleep rules, advanced capture/recording editing, reviewed app leftovers, full command-bar indexing, additional radial gesture work and rendered validation, and localization. DDC/CI, NVIDIA readings, global clipboard-preserving plain paste, download review and named launcher profiles are implemented; their validation limits are documented separately. A Windows build and runtime verification are prerequisites to calling this a finished port.

## Design mapping

The macOS menu bar becomes one Shell notification-area icon plus a compact Mica window anchored to its monitor/work area. Settings uses NavigationView, Fluent cards and native toggles. Onboarding keeps the original sequence of welcome → feature/preset choice → selected access explanations → completion. It replaces macOS permission prompts with accurate Windows desktop access descriptions. There is no Dynamic Island, Liquid Glass, screen capture permission, administrator requirement, or default startup registration.

Mica is a wallpaper-tinted backdrop, not a transparent pane showing live windows behind it. Windows owns its inactive, transparency-disabled, energy-saver and high-contrast fallbacks. See [Microsoft Mica guidance](https://learn.microsoft.com/en-us/windows/apps/design/style/mica).
